Bootstrap 6 alpha

Bootstrap 6.0.0-alpha.1

Opens the v6 docs. This is not the stable release.

What Lines Up

  • UiButton and Buttons, including an icon-only button. The class names differ.
  • UiBreadcrumb and Breadcrumb. v6 uses breadcrumb-link and a divider element.
  • UiInput, UiCheckbox, and UiForm and the form controls. v6 puts the check class on the input.
  • UiToggle and Switch.
  • UiSelect and UiMultiSelect and Combobox, the new searchable select with a multi-select mode.
  • UiDatePicker and Datepicker.
  • UiPagination, UiTable, UiAlert, UiBadge, UiCard, UiText, UiTabs, and UiSpinner.
  • UiDialog and Dialog. Both use a native dialog. Figma still calls this a modal.
  • UiDropdownMenu and Menu. v6 renamed Dropdown to Menu.
  • UiDrawer and Drawer share the name. The implementation does not.
  • Global Messages and Toast.

Bootstrap 6 alpha

Bootstrap 6.0.0-alpha.1

Opens the v6 docs. This is not the stable release.

What Lines Up

These Figma pages still exist in Bootstrap 6. Several are renamed or restyled. Open a card when the two sides do not match.

  • Accordion, alerts, badges, breadcrumbs, buttons, card, pagination, spinner, switch, tables, tabs, and tooltips.
  • Dropdown is now Menu. Modal is now Dialog. Offcanvas is now Drawer.
  • Toast, popover, list group, and progress are still in Bootstrap 6.
  • Colors, borders, radius, shadows, and typography are still documented, on new scales.

Discrepancies

Discrepancy

Menu selected state

Figma’s dropdown active row is full width. v6 rounds it.

Discrepancy

Carousel arrows and dots

Figma puts them on the slide. v6 puts them in a row underneath.

Discrepancy

Modal and dialog

Figma documents Modal. v6 replaces it with Dialog.

Discrepancy

Offcanvas and drawer

Figma marked offcanvas to be removed. v6 ships it as Drawer.

Discrepancy

Colors

Figma shows the current swatches. v6 uses oklch and theme classes.

Discrepancy

Spacing

Figma stops at 32 and is marked to be removed. v6 remaps the scale.

Discrepancy

Pages marked to be removed

Progress, popovers, and list group are still in Bootstrap 6.
